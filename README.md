# IsingProject
Physics 272H project at UMD. Some playing around with the Ising model and Monte Carlo methods.

The python script can take a cmd line argument for the size of the simulation. On my M6 Macbook Pro 1000 works quite well (its also the default).
In dist, a build for MacOs is provided. It was built on November 7th, 2026. I kind of messed up the package management, but if you'd like to build this you on your own, you will need Numba, Numpy, Scipy, and MatplotLib. Good luck with that, I definately need to find a good way to track packages in python...
